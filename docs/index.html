b.roll

A flight recorder for your terminal. Record sessions, search output, annotate findings, extract commands.

View on GitHub Installation
$ cargo install --git https://github.com/rodbove/broll

Built for power users

Everything you need to never lose terminal output again.

🔍

Full-text search

SQLite FTS5-powered search across all your recorded sessions. Find that error message from last week in seconds.

🔒

Secret filtering

Automatically redacts passwords, tokens, AWS keys, JWTs, and database URLs before they hit disk. On by default.

📄

Command extraction

Pull out just the commands from any session and save them as a runnable shell script. Turn debugging into documentation.

🔗

Session groups

Correlate multiple terminals working on the same task. Tag sessions, group them, and search across the whole context.

🏷

Session management

Name sessions for instant recall, add notes with annotate, rename them later, or delete old ones. No more remembering hex IDs.

💻

TUI interface

Browse sessions and search results in a keyboard-driven TUI. Search within sessions with /, jump from search results into full session view with Enter.

How it works

1

Start recording

Run broll start to spawn a sub-shell inside a PTY in your current directory. Everything flows through broll transparently.

2

Work normally

Your shell works exactly as before. Commands and output are captured with timestamps in the background.

3

Exit to save

Exit the shell or run broll stop. The session is indexed and searchable immediately.

4

Search and extract

Use broll search to find output across sessions, or broll extract to get commands as a script.
